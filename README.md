# Python OOP Project

This is a simple Python project made to practice Object-Oriented Programming (OOP).  
It contains a few small systems built using classes and objects.

---

## 📦 What’s Inside

### 📚 Library System
Manages books and counts total books in the system.

### 🛒 Shopping Cart
Adds items, applies discount, and calculates total price.

### 🏦 Bank Account
Handles deposits, withdrawals, and balance updates.

### 🎓 Student System
Stores student data and checks if a student is an honor student.
