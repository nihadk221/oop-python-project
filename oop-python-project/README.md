# OOP Python Mini Project

This project demonstrates basic Object-Oriented Programming (OOP) concepts in Python using four systems:

## 📚 Features

### 1. Library System
- Tracks books
- Class variable for total books
- Book summary method

### 2. Shopping Cart
- Add items
- Apply discount
- Calculate total price

### 3. Bank Account
- Deposit and withdraw money
- Balance tracking
- Bank name as class variable

### 4. Student System
- Student counter
- GPA tracking
- Honor student check

python main.py
